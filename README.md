# 卡组印坊

简体中文宝可梦 PTCG 卡组分享导入与 A4 打印 PDF 工具。

网站直接在浏览器中读取集换社公开分享卡组，不依赖自有服务器，也不包含 API Key。

线上地址：https://passtar44.github.io/ptcg-zh-site/

## 功能

- 粘贴集换社卡组分享链接，读取原卡图和数量
- 核对卡面与数量
- 生成 A4、每页 9 张的打印 PDF
- 默认 1 mm 紧凑间距，可沿卡间空隙单线裁切
- 自动使用卡组标题命名 PDF
- 支持裁切标记和 50 mm 校准尺

## 隐私

- 卡组链接只发送给集换社公开 API
- 卡图直接从集换社 CDN 读取
- PDF 在浏览器本地生成
- 不收集或上传用户卡组数据

## 部署

推送到 `main` 后，`.github/workflows/pages.yml` 会通过 GitHub Pages 自动发布。
